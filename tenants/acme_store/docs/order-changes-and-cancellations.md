# Changing or Cancelling an Order

## Cancelling
You can cancel an order while its status is **Processing**. Contact support with your order number and we cancel it
and refund the full amount.

Once an order has **shipped** it cannot be cancelled. You can refuse the delivery, or return it after it arrives
under our returns policy.

## Changing the delivery address
We can change the delivery address only while the order is Processing. After the order has shipped, the address
cannot be changed; contact the carrier with your tracking number to ask about redirecting.

## Changing items
We cannot add or remove items from an existing order. Cancel the order and place a new one.
