# Admissions and Demo Classes

> SAMPLE CONTENT: invented for this demo. The institute's real admission steps may differ.

## How admission works
1. Submit an enquiry on the website or ask for a call back.
2. Speak to a counsellor about the programme that suits you.
3. Attend a free demo class if you want to try one.
4. Complete the registration form and pay the first instalment.
5. Receive an admission confirmation email with your batch id and timing.

## Demo classes
A demo class is free and has no obligation to join. Demo classes are scheduled by the counselling team; ask for
the next available slot when you enquire.

## Batch id
Your batch id looks like PYF-101. Quote it whenever you contact support.

## Changing batch
A request to move to another batch of the same programme is made to the support team. It depends on seat
availability and is not guaranteed.

## Seat confirmation
A seat is confirmed only after the first instalment is received. Filling in the enquiry form does not reserve a seat.
