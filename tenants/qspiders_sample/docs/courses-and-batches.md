# Courses and Batches

> SAMPLE CONTENT: invented for this demo. Course names, durations and timings are not the institute's real catalogue.

## Programmes
| Programme | Brand | Duration | Modes |
|---|---|---|---|
| Python Full Stack | PySpiders | 24 weeks | online or offline |
| Data Science with Python | PySpiders | 28 weeks | online |
| Software Testing | QSpiders | 16 weeks | offline |

## Python Full Stack
Covers Python basics, object-oriented programming, SQL, the Flask web framework, REST APIs, Git and a capstone
project. No prior coding experience is needed.

## Data Science with Python
Covers Python, NumPy, Pandas, data cleaning, visualisation, statistics and an introduction to machine learning.

## Software Testing
Covers testing fundamentals, test design techniques, the defect life cycle, SQL for testers, API testing and an
introduction to Selenium automation.

## Batch timings
Weekday batches run Monday to Friday. Weekend batches run on Saturday and Sunday. Evening batches are available
at some offline centres. The batch timing is confirmed in your admission confirmation email.

## Online and offline batches
Online batches are live classes over video. Offline batches are held at a training centre. A student attends the
mode they enrolled in; changing mode needs a request to the support team.
